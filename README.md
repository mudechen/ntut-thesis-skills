# NTUT Thesis Skills / 北科大碩論輔助 Skills

專門為**國立臺北科技大學**研究生設計的 Antigravity AI 論文撰寫輔助技能包。

> AI 是副駕駛，不是機長。這套 skill 處理格式苦工，讓你專注在真正需要你腦子的事。

## 📦 包含的 Skills

| Skill | 說明 | 觸發詞 |
|-------|------|--------|
| [ntut-thesis](./skills/ntut-thesis/SKILL.md) | 北科大碩論格式規範全覆蓋，含撰寫輔助 | 「論文格式」「幫我寫章節」「摘要怎麼寫」 |

## 🎯 功能涵蓋

- 📋 **裝訂順序**：14 步驟完整說明（封面→書名頁→審定書→摘要→…）
- 📄 **頁碼雙系統**：篇前羅馬數字 i/ii/iii，正文阿拉伯數字 1/2/3
- 🔤 **字型規範**：各層級字型（標楷體/Times New Roman，20pt/18pt/12pt…）
- 📐 **邊界規格**：A4、左右上 2.5cm、下 2.75cm
- 📊 **圖表格式**：表標題在上、圖標題在下，中文不加句點，分章編號
- ➗ **方程式**：`(章.序號)` 編號，靠右對齊，斜體符號
- 📚 **引用格式**：北科方括號 `[1][2]` 格式，書籍/期刊/會議/學位論文範例
- 🖊️ **5 種工作模式**：格式諮詢、章節撰寫、格式檢查、文獻整理、大綱規劃

## 🚀 安裝方式

將 `skills/` 資料夾放置於你的碩論專案根目錄，或在 Antigravity config 中指定路徑。

```
碩論/
└── skills/
    └── ntut-thesis/
        └── SKILL.md
```

## 📖 格式依據

北科大官方論文格式規範書（114.02.01 版）
